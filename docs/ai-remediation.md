# 🧠 AI Smart Remediation & Root Cause Analysis

DriftSentry includes an LLM-powered remediation engine that transforms raw drift data into **production-ready, idiomatic HCL code** and **executive-ready root-cause explanations**.

---

## 🌟 Why AI Remediation?

Traditional drift remediation tools either leave you with manual `terraform import` commands or raw JSON attribute dumps that fail `terraform validate`.

DriftSentry's AI engine solves this:
- 🏗️ **Idiomatic HCL**: Generates native nested blocks (e.g. `ingress`/`egress` rules, S3 encryption blocks) instead of flattened dictionaries.
- 🛡️ **Lifecycle Management**: Automatically detects volatile attributes and adds `lifecycle { ignore_changes = [...] }`.
- 🕵️ **Root Cause Narratives**: Correlates CloudTrail events to explain *who* drifted the resource, *how* (AWS Console ClickOps vs CLI), and the *security risk*.
- 🤖 **Enriched Pull Requests**: Generates GitHub PR descriptions containing full root-cause breakdowns and recommended actions.

## ⚙️ Supported Providers & Setup

### 1. Anthropic Claude (Default)
Recommended for high accuracy and clean HCL structuring.

```bash
# Install AI dependencies
pip install "driftsentry[ai]"

# Set Anthropic API Key
export ANTHROPIC_API_KEY="sk-ant-api03-..."

# Run remediation
driftsentry remediate --ai --ai-provider claude
```

Default model: `claude-sonnet-4-6` (fast and cost-effective). You can override with `--ai-model claude-opus-4-6`.

---

### 2. Google Gemini
Recommended for ultra-fast analysis and cost efficiency.

```bash
# Set Gemini API Key
export GEMINI_API_KEY="AIzaSy..."

# Run remediation
driftsentry remediate --ai --ai-provider gemini
```

Default model: `gemini-2.5-flash`. You can override with `--ai-model gemini-2.5-pro`.

## 📋 What Gets Generated

When you run `driftsentry remediate --ai`, DriftSentry generates:

```
driftsentry-remediation/
├── import.sh                  # Executable shell script with terraform/tofu import commands
├── imported_web_sg.tf         # AI-generated idiomatic HCL code block
├── revert_plan.json           # Detailed JSON attribute diff plan
├── revert_instructions.md     # Step-by-step revert instructions with AI root cause callouts
└── REMEDIATION_SUMMARY.md     # Full remediation summary with AI security insights
```

### Example: AI-Generated HCL Block (`imported_web_sg.tf`)

```hcl
resource "aws_security_group" "web_sg" {
  name        = "web-server-sg"
  description = "Managed web security group"
  vpc_id      = "vpc-0abc123def456789"

  ingress {
    description = "HTTPS from corporate CIDR"
    from_port   = 443
    to_port     = 443
    protocol    = "tcp"
    cidr_blocks = ["10.0.0.0/8"]
  }

  egress {
    from_port   = 0
    to_port     = 0
    protocol    = "-1"
    cidr_blocks = ["0.0.0.0/0"]
  }

  tags = {
    Environment = "production"
    ManagedBy   = "DriftSentry"
  }

  lifecycle {
    ignore_changes = [tags_all]
  }
}
```

## 🔒 Security & Privacy Notes

- **Zero Telemetry**: DriftSentry does not send your data anywhere except directly to your configured Anthropic or Google API endpoint.
- **Batching & Caps**: Drift items are batched (5 items/request) and capped by default to `--ai-max-items 20` to prevent unexpected API costs.
- **Graceful Fallback**: If API keys are unset or network issues occur, DriftSentry automatically falls back to standard template remediation.
